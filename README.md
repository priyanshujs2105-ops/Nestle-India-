Nestlé India — FP&A Budgeting & Forecasting Model

«An Excel-based FP&A project demonstrating budgeting, 12-month forecasting, variance analysis, financial modelling, and management reporting using publicly available financial data.»

---

📌 Project Overview

This project builds a practical Financial Planning & Analysis (FP&A) model for Nestlé India using publicly available annual and quarterly financial information.

The objective was to simulate a simplified FP&A environment where historical performance is analyzed, monthly estimates are constructed, budgets are prepared, future performance is forecasted, and variances are presented through management-focused dashboards.

The model focuses on the complete planning cycle:

Historical Analysis → Derived Monthly Data → Budget → Rolling Forecast → Variance Analysis → Management Insights

---

🎯 Objectives

- Build a structured FP&A budgeting model in Excel
- Convert quarterly financial information into derived monthly estimates
- Develop a 12-month forward rolling forecast
- Perform Budget vs Actual analysis
- Perform Budget vs Forecast analysis
- Analyze Revenue, COGS, Operating Expenses and EBITDA
- Track EBITDA and PAT performance
- Build management-oriented dashboards
- Incorporate model validation and reconciliation checks
- Document assumptions and limitations clearly

---

🧩 Model Structure

The workbook is organized into the following major sections:

Module| Purpose
Historical Financials| Analyze reported historical financial performance
Derived Monthly Actuals| Convert quarterly data into analytical monthly estimates
Monthly Budget| Build a revenue and cost budget using defined assumptions
Rolling Forecast| Project the next 12 months from the latest available period
Budget vs Actual| Measure actual/derived performance against budget
Budget vs Forecast| Compare expected performance with the original budget
Ratio Analysis| Evaluate profitability and financial trends
FP&A Dashboards| Present KPIs, trends and variances for management review
Model Checks| Validate calculations, reconciliations and key assumptions
Executive Summary| Summarize methodology, findings and limitations

📊 Key FP&A Components

1. Budgeting

The budget is driven by explicit revenue and cost assumptions.

Key budget assumptions include:

- COGS: 38.8% of Revenue
- Employee Cost: 10.2% of Revenue
- Other Opex: 28.1% of Revenue
- Total Opex: 77.1% of Revenue
- EBITDA Margin: 22.9%

The model directly links these assumptions to the budgeted P&L.

---

2. Derived Monthly Financials

Nestlé India's publicly available financial information does not provide all of the monthly P&L granularity required for this project.

Therefore, quarterly figures were converted into derived monthly estimates using explicitly documented assumptions.

The quarterly allocation methodology uses:

31% → 33% → 36%

for the three months of a quarter.

The derived monthly figures are then reconciled back to the reported quarterly totals.

«Important: These are analytical estimates created for this project and should not be interpreted as Nestlé India's reported monthly financial results.»

---

3. 12-Month Rolling Forecast

A forward-looking forecast is built from the latest available/derived actual period.

The forecast incorporates assumptions for:

- Revenue growth
- COGS
- Employee costs
- Other operating expenses
- Depreciation
- Interest
- Tax

The model is designed as a portfolio-level FP&A demonstration, rather than a representation of Nestlé India's internal forecasting system.

---

📈 Variance Analysis

The project includes two major variance views:

Budget vs Actual

Evaluates how performance compares with the original plan.

Key metrics include:

- Revenue variance
- EBITDA variance
- EBITDA margin
- PAT
- Monthly trends
- Cost structure
- Management commentary

Budget vs Forecast

Evaluates the latest expected performance against the original budget.

Example:

Budget Revenue: ~₹26,373 Cr
Forecast Revenue: ~₹26,852 Cr
Forecast vs Budget: +1.82%

The model also analyzes the effect of cost assumptions on EBITDA and profitability.

---

🔍 Variance Analysis Approach

The project distinguishes between model-driven explanations and potential operational drivers.

For example:

«A higher forecast COGS percentage than budget explains the mathematical COGS variance.»

In a real FP&A environment, the next step would be to investigate operational drivers such as:

- Price
- Volume
- Product mix
- Raw-material costs
- Procurement
- Production efficiency
- Headcount
- Marketing expenditure
- Distribution costs

These operational explanations were not fabricated where supporting company-level data was unavailable.

🧪 Model Validation

The workbook contains dedicated model checks covering:

- Quarterly-to-monthly reconciliation
- Seasonality allocation
- Cost-mix allocation
- Budget assumptions
- Forecast assumptions
- Revenue checks
- EBITDA calculations
- Profitability calculations
- Budget vs Actual consistency
- Forecast linkage
- Formula error checks

The purpose is to ensure that assumptions flow correctly through the model and that derived figures reconcile to their source totals.

---

⚠️ Key Limitations

This project is intended as a portfolio and analytical demonstration, not as Nestlé India's internal FP&A model.

Key limitations include:

1. Monthly financial figures are derived from publicly reported quarterly information.
2. Monthly seasonality is based on an explicit allocation assumption.
3. Monthly cost components are reconstructed using an assumed cost mix.
4. Depreciation and interest forecasting uses simplified methodologies.
5. Publicly available data does not provide the operational drivers normally available to an internal FP&A team.
6. FY2023–24 was a 15-month transition year following Nestlé India's change from a January–December financial year to an April–March financial year and therefore requires caution when comparing it with normal 12-month periods.

💡 Key Takeaway

The main objective of this project was not simply to forecast Nestlé India's numbers.

It was to demonstrate how an FP&A analyst can take incomplete public financial information, establish transparent assumptions, build a structured planning model, validate the outputs, and convert the analysis into management-focused financial insights.
